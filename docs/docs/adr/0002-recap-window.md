# ADR 0002：跨会话接话用「时间间隔 + 最近 3 轮原话」

日期：2026-10-26
状态：已采纳

## 背景

同一段关系可以聊上百轮。靠记忆条目概括会丢语气和细节；靠全量历史会撑爆上下文。用户的原话是：「记住最后 3-5 句，每次只说最后几句」。

## 决定

注入块在「距上一条消息超过 30 分钟」时，追加最近 3 轮的一问一答原话（每句截 60 字）+ 一行「上次聊天（多久前）」；刚聊完的会话不重复注入（那段还在上下文里）。

## 理由

- 不用 sessionId：新开窗口、重启宿主、QQ 与 GUI 切换都能接上。
- 代价可控：3 轮约 300 字，不到注入预算的 1/6。
- 语气和细节来自原话，比抽取出的摘要更像「还记得你刚说到哪」。
- 更早的内容仍然靠抽取压缩成记忆，不丢。

## 代价

- 30 分钟这个阈值是拍的：太短会在长对话里重复注入，太长接不上话。可配置。
- 注入的是原文，可能带出旧话题；靠「只是判断素材」的措辞约束，不强制。
